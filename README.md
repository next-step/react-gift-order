# 미션 2 - 2단계 - 주문하기 페이지 구현하기

## 구현 내용

### 로그인 정보

- 로그인 정보를 어디서든 사용할 수 있습니다. (Context API)
- 새로고침을 하더라도 로그인 정보가 유지됩니다. (localStorage)
- 로그인한 유저는 로그인 버튼 클릭 시 마이페이지(`/my`)로 이동합니다.
- 마이페이지는 로그인한 사람만 접근 가능하며, 비로그인 사용자는 로그인 페이지(`/login`)로 리다이렉트됩니다.
- 마이페이지에서 로그아웃할 수 있으며, 로그아웃 시 로그인 페이지로 이동합니다.

### 주문하기

- 상품 아이템을 클릭하면 주문하기 페이지(`/order/:productId`)로 이동합니다.
- 비로그인 상태에서 주문 페이지 접근 시 로그인 페이지로 이동하며, 로그인 성공 시 원래 주문 페이지로 복귀합니다.
- [참고 URL](https://kakaotech-mission2-order-step2.pages.dev/)을 참고하여 주문하기 UI/UX를 구현했습니다.
- 주문 폼에는 카드 템플릿 선택, 메시지, 보내는 사람, 받는 사람, 전화번호, 수량 입력란이 있습니다.
- 버튼 클릭 시 아래 유효성 검사 조건이 충족되지 않으면 각 폼 필드에 안내 메시지를 보여줍니다.
  - 메시지는 반드시 입력되어야 합니다. ("메시지를 입력해주세요.")
  - 보내는 사람 이름이 반드시 입력되어야 합니다. ("이름을 입력해주세요.")
  - 받는 사람 이름이 반드시 입력되어야 합니다. ("이름을 입력해주세요.")
  - 받는 사람 전화번호는 반드시 입력되고, 010-xxxx-xxxx 형식이어야 합니다. ("올바른 전화번호 형식이 아닙니다.")
  - 수량은 1개 이상이어야 합니다. ("구매 수량은 1개 이상이어야 합니다.")
- 모든 정보가 올바르게 입력되면 주문 완료 안내 메시지가 뜨고, 확인 시 메인페이지로 이동합니다.

---

### 기타

- 스타일은 Emotion(styled-components)로 분리하여 일관성 있게 관리합니다.
- 카드 템플릿, 상품 데이터 등은 mock 데이터로 구성되어 있습니다.
