### 로그인 관리
Context API와 쿠키 혹은 세션 스토리지를 사용해 로그인 상태를 저장합니다.
   - 새로고침 후에도 로그인 정보를 유지합니다.
   - 로그인 후 로그인 버튼을 누르면 마이페이지(`/my`)로 이동합니다.
   - 마이페이지에서 로그아웃하면 로그인 페이지(`/login`)로 되돌아갑니다.

### 라우팅 제어
마이페이지(`/my`)는 로그인한 사용자만 접근할 수 있도록 보호합니다.
   - 로그인하지 않은 사용자가 접근 시 로그인 페이지로 리다이렉트합니다.

### 주문하기 페이지
상품 아이템 클릭 시 주문하기 페이지로 이동합니다.
   - 비로그인 상태라면 먼저 로그인 페이지로 이동시킨 후, 로그인 성공 시 주문 페이지로 돌아오도록 처리합니다.
주문 폼을 구현하고 다음 조건을 검증합니다.
   - 메시지는 필수 입력 값입니다.
   - 보내는 사람 이름은 필수입니다.
   - 받는 사람 이름은 필수입니다.
   - 받는 사람 전화번호는 `01012341234` 형식에 맞아야 합니다.
   - 수량은 1개 이상이어야 합니다.
메시지 카드 템플릿 목데이터를 활용해 카드 선택 UI를 제공합니다.
