# 미션 2 - 3단계 - 단체 주문 기능 구현하기

## **목표**

✔️ 복잡한 폼과 유효성검사를 구현해요.

✔️ React Hook Form + Zod를 사용하여 어떤 점들이 좋아졌는지 경험해봐요.

## **과제 진행 요구사항**

- 본인만의 기준으로 일관된 코드를 작성해주세요.
- 기능 단위로 나누어 커밋을 해주세요.
- 재사용 가능성이 높은 컴포넌트, Hooks가 보이면 재사용성을 고려하여 만들어요.
- 주문하기 페이지의 폼을 React Hook Form를 사용해서 리팩터링해요. (form 데이터를 useState로 다루는 경우는 없게 해요.)
- 받는 사람 기능 고도화
  - [참고 URL](https://kakaotech-mission2-order.pages.dev/)을 살펴보고 받는 사람 기능의 UI를 구현해요.
  - 받는 사람을 최대 10명까지 등록 가능하게 해요.
  - 10명의 정보가 정확하게 입력되지 않으면 정보가 반영되지 않아요.
  - 받는 사람의 전화번호가 중복되면 안돼요.
  - 최소 선택 수량은 1개 이상이어야 해요.
  - 전화번호는 01012341234 형태로만 받을 수 있어요.
- 주문하기 페이지 고도화
  - [참고 URL](https://kakaotech-mission2-order.pages.dev/)을 살펴보고 변경된 기능을 구현해요.
- (선택) 유효성 검사를 Zod 라이브러리를 사용해서 처리해요.
