# react-gift-order

## 구현할 기능 목록

### 로그인 정보

- ContextAPI를 이용하여 로그인 정보 관리
- 로그인 한 유저는 로그인 버튼 클릭 시 마이페이지(/my)로 연결
- 로그인 하지 않은 사람이 접속하면 로그인 페이지로 연결
- 마이페이지에서 로그아웃 가능, 로그아웃 시 로그인(/login) 페이지로 연결

### 주문하기

- 상품 아이템을 클릭하면 주문하기 페이지로 연결
- 만약 로그인이 되어있지 않다면 로그인을 유도, 로그인 성공 시 주문하기 페이지로 접근
- 주문하기 버튼 클릭 시 아래 유효성 검사 조건이 충족되지 않으면 각 폼 필드에 안내 메시지 출력
  - 메시지, 보내는 사람, 받는 사람 이름, 받는사람 전화번호가 는 반드시 입력
  - 전화번호 규칙: 01012341234
    - 요구사항은 010-0000-0000 형식이 없었지만 참고 URL에 구현된 페이지에는 두 방식 모두 가능하여 두개다 구현하였습니다.
  - 수량은 1개 이상
