# react-gift-order

## 구현할 기능 목록

### 받는 사람 기능 고도화

- 받는 사람 기능의 UI를 구현
- 받는 사람을 최대 10명까지 등록 가능
- 10명의 정보가 정확하게 입력되지 않으면 정보가 반영되지 않는다
- 받는 사람의 전화번호가 중복 불가
- 최소 선택 수량은 1개 이상
- 전화번호는 01012341234 형태로만 받을 수 있다

### 주문하기 페이지 고도화

- 유효성 검사를 Zod 라이브러리를 사용해서 처리

## 후기

- form 구현 과정에서 react-hook-form과 zod를 사용했는데 아직 미숙하다 보니 코드 가독성과 Props 처리가 많이 부족했습니다.
